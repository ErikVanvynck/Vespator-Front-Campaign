Images are resized to 256 px and saved in this browser. Transparent PNGs/WebPs work best.

Quick guide

Drag markers to move them. Click a marker to edit its name, symbol, color, notes, or upload a custom image. Use Add token to create a marker. PNG images with transparent backgrounds work particularly well.

Export save downloads a JSON backup; Import save restores one.

This first version stores data in this browser only. For players to share one map live, follow the Firebase steps in the included README.
